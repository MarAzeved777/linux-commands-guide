# Linux Commands Guide 🐧

Um guia simples de comandos básicos do Linux.

## Comandos

### pwd
Mostra o diretório atual.

### ls
Lista os arquivos e pastas.

### cd
Entra em uma pasta.

### mkdir
Cria uma nova pasta.

### touch
Cria um novo arquivo.

### clear
Limpa a tela do terminal.

### rm
Remove um arquivo.

### whoami
Mostra o usuário atual.
