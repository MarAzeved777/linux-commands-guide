# Exercícios de Linux

## Exercício 1 — pwd

**Pergunta:** O que o comando `pwd` mostra?

**Resposta:** O diretório atual.

## Exercício 2 — ls

**Pergunta:** Para que serve o comando `ls`?

**Resposta:** Para listar arquivos e pastas.

## Exercício 3 — mkdir

**Pergunta:** Para que serve o comando `mkdir`?

**Resposta:** Para criar uma nova pasta.
