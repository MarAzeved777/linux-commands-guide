# Linux Commands Guide 🐧

Um guia simples para aprender comandos básicos do Linux.

## 📚 Conteúdo

Este projeto apresenta comandos essenciais para quem está começando a usar Linux.

### Comandos disponíveis

- `pwd` — mostra o diretório atual
- `ls` — lista arquivos e pastas
- `cd` — entra em uma pasta
- `mkdir` — cria uma pasta
- `touch` — cria um arquivo
- `clear` — limpa o terminal
- `rm` — remove um arquivo
- `whoami` — mostra o usuário atual

## 🎯 Objetivo

Criar uma referência simples para iniciantes aprenderem os primeiros comandos do Linux.

## 👨‍💻 Projeto

Projeto criado para praticar Git, GitHub e conceitos básicos de Linux.
